# Added wallpaper sources and licenses

All 32 added records use artwork from the official [KDE Plasma Workspace Wallpapers](https://github.com/KDE/plasma-workspace-wallpapers) collection, pinned to commit [`3e4537eb3852a1c769f6fa003e74d06260c266fb`](https://github.com/KDE/plasma-workspace-wallpapers/tree/3e4537eb3852a1c769f6fa003e74d06260c266fb). Images were retrieved on 2026-10-19 through the GitHub API and decoded before integration. Licenses and authors below come from each artwork’s own `metadata.json`, not from the repository’s general license file.

- CC BY-SA 4.0: 16 delivered files (official license text: [`public/licenses/CC-BY-SA-4.0.txt`](../Front%20End%20Project/public/licenses/CC-BY-SA-4.0.txt); canonical URL: https://creativecommons.org/licenses/by-sa/4.0/)
- LGPLv3: 16 delivered files (official license text: [`public/licenses/LGPL-3.0.txt`](../Front%20End%20Project/public/licenses/LGPL-3.0.txt); canonical URL: https://www.gnu.org/licenses/lgpl-3.0.html)

Eleven delivered images are byte-identical to the source file. Twenty-one were resized without cropping to fit within 2560×1600 and re-encoded as JPEG at quality 90; those changes are recorded per item. The source paths and SHA-256 hashes document the exact upstream files.
